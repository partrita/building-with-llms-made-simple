# SciPy 2025 튜토리얼 제안

## 초록

이 튜토리얼에서는 대규모 언어 모델(LLM)을 단순한 추가 기능이 아닌, 신중하게 설계된 프로그램의 핵심 구성 요소로 파이썬 프로그램에 직접 통합하는 방법을 배웁니다. 이 실습 세션에서는 LLM 출력을 프로그램 제어 흐름에 통합하기 위한 설계 원칙과 실제 기술을 가르칩니다. 오픈 소스 파이썬 LLM 인터페이스인 LlamaBot을 사용하여 로컬에서 효율적인 모델을 실행하는 데 중점을 둘 것입니다.

## 설명

이 실습 튜토리얼에서는 LlamaBot과 Ollama를 사용하여 대규모 언어 모델(LLM)을 파이썬 프로그램에 실질적으로 통합하는 방법을 가르칩니다. 16GB RAM 내에 맞는 로컬 실행 모델로 작업하면서, 참가자들은 git 커밋 메시지 생성기를 만들며 LLM 애플리케이션 개발의 핵심 개념을 배우게 됩니다.

Jupyter 노트북을 통해 `SimpleBot`을 사용한 기본 LLM 상호 작용에서 시작하여 Pydantic을 사용한 구조화된 출력으로 진행하고, 체계적인 평가와 실제 배포로 마무리합니다. 이 튜토리얼은 직접 해보는 학습을 강조합니다: 참가자들은 다양한 모델, 프롬프팅 전략, 온도 설정을 실험하여 출력 품질에 미치는 영향을 이해하게 됩니다.

주요 학습 결과에는 프롬프트 설계 마스터하기, 스키마 유효성 검사를 통한 구조화된 생성 구현, 체계적인 평가 접근법 개발, LLM 기반 기능을 기존 워크플로우에 통합하기 등이 포함됩니다. 세션은 LLM 애플리케이션의 실제 적용에 대한 광범위한 함의에 대해 수강생이 선택한 토론으로 마무리됩니다.

## 전제 조건

- 파이썬 프로그래밍 경험
- 하드웨어 요구 사항:
  - Mac: 최소 16GB RAM
  - Linux/Windows: 16-32GB RAM
- Ollama 및 `smollm2`, `gemma2:2b`, `mistral`, `phi4` 모델을 설치하고 실행할 수 있는 능력

## AI 사용

손목 터널 증후군이 있어 타이핑 보조 도구로 AI를 사용했습니다. 구체적으로, 이 제안서는 제 머릿속의 내용을 Whisper(음성-텍스트 변환)를 사용하여 초안으로 작성했습니다. 그런 다음 Claude 3.5 Sonnet을 사용하여 SciPy 제출 형식으로 변환했습니다. 주로 Whisper 전사를 통해 약 70% 정도 많이 편집되었습니다.

## 개요

1부: `SimpleBot`을 이용한 LLM API 소개 (45분)

- LlamaBot을 API 프론트엔드로, Ollama를 로컬 LLM 제공자로 사용합니다.
- 실습: `llamabot.SimpleBot`을 생성하여 언어 모델과 상호 작용하기.
  - 간단한 메모: LLM API 호출의 구조: 시스템 프롬프트, 사용자 프롬프트, 온도, 모델 이름.
  - 연습: "Hello LLM!". 시스템 프롬프트를 변경하여 LM 페르소나 설정, 응답의 다양성을 높이기 위해 온도 변경, 사용자 의도에 따라 사용자 프롬프트 변경
  - 연습: git 커밋 메시지 생성기 프로토타입의 안내된 빌드. 시스템 프롬프트, 온도, 사용자 프롬프트 변경; 출력 결과 분위기 확인.
  - 연습: LLM 모델을 변경하고 출력 결과 분위기 다시 확인.
  - 데모: `gpt-4o` 대 `llama3.2`를 사용한 출력 + 튜토리얼 클래스 평가 토론.
- 핵심 개념:
  - API 호출은 상태 비저장/기억이 없습니다.
  - 프롬프트는 우리가 필요로 하는 작업을 수행하도록 LM을 유도하기 위해 설계될 수 있습니다(엔지니어링이 아님!).
  - 분위기 확인은 LLM을 평가할 때 가장 먼저 해야 할 일입니다.

휴식 (15분)

2부: 구조화된 출력 `StructuredBot` (45분)

- 사전 지정된 스키마를 따르는 출력을 생성하기 위해 `StructuredBot`의 사용을 소개합니다.
- 간단한 강의: 구조화된 출력이 생성되는 방법:
  - JSON을 얻기 위한 프롬프팅.
  - 로짓 마스킹. <-- 이것은 대부분의 최신 LM이 어떻게 작동하는지 보여줄 완벽한 기회를 제공할 것입니다: 자기회귀 생성.
- 실습: git 커밋 메시지 생성기를 자유 텍스트에서 구조화된 형식으로 재구성하기.
  - 연습: git 커밋 메시지를 구성 요소로 분해하고, Pydantic 모델로 구현하고, `StructuredBot`을 사용하여 커밋 메시지를 생성하고 형식을 지정합니다.
  - 연습: 이모지를 추가하여 git 커밋 메시지에 재즈와 멋을 더하세요!
  - 연습: 커밋 메시지 형식을 지정하기 위한 사용자 정의 클래스 메서드 추가.
- 핵심 개념:
  - 템플릿화된 텍스트는 형식이며, Pydantic을 사용하여 모델링하고, 구조화된 생성 방법을 사용하여 채웁니다.
  - LLM이 생성해야 하는 콘텐츠는 충분한 컨텍스트가 제공되어야 합니다.

휴식 (15분)

3부: 평가 및 LLM 기반 텍스트 생성을 제품에 통합하기 (45분)

- LLM 생성 텍스트 평가 방법론을 소개합니다.
- 그룹 실습: 평가
  - 클래스 그룹 연습: 선별된 커밋 메시지에 대해 커밋 메시지의 정확성을 체계적으로 평가합니다. 커밋 메시지 작성자가 정보를 놓치는 부분을 비판합니다. 추가 컨텍스트가 제공되어야 할 부분을 식별합니다(예: 변경 의도 - 일반적으로 코드에서는 사용할 수 없음).
  - 연습: git 커밋 메시지 작성기에 대한 변경 사항을 제안하고 구현합니다.
- 실습: LLM 기반 텍스트 생성을 제품에 통합하기
  - 연습: 커밋 메시지를 자동으로 작성하는 셸 실행 파일에 텍스트 생성을 통합합니다.
  - 데모: LlamaBot이 더 나아가 git의 `prepare-commit-msg` 훅에 직접 연결되는 방법을 보여줍니다.
- 핵심 개념:
  - 체계적인 평가에는 노력이 필요하며, 투입되는 노력은 생성된 텍스트의 영향에 비례해야 합니다.
  - LLM 텍스트 생성을 운영화하려면 워크플로우 통합에 대한 사려 깊은 고려가 필요합니다.

휴식 (15분)

4부: 수강생 선택 토론 (20분)

- 네 가지 선택:
  - 옵션 1: LLM 강화 애플리케이션을 위한 설계 원칙.
  - 옵션 2: 자신의 작업을 가속화하기 위해 LLM을 적용하기 위한 아이디어 브레인스토밍.
  - 옵션 3: GenAI 시대의 데이터 과학 역할의 미래는?
  - 옵션 4: 윤리 토론.
- 수강생은 투표로 선택합니다. 가장 인기 있는 것이 이깁니다.
